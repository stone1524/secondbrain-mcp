# 路线图

## v0.1 — 2026-10-20（简历可写版本）

**证明的事**：我能把一个真实运行的个人系统，安全地抽成带测试、带 CI、带红线管理的开源工程。

- 安全机制三件套：哈希锁写 / 无删除归档回滚 / 隐私分区
- 关键词检索全量可用；语义检索接通至少一个 provider
- demo vault（合成内容）+ 快速开始文档
- pytest + ruff + GitHub Actions 全绿

## v0.2 — 2026-11 月中（面试演示版）

**证明的事**：检索质量是量化验收的，不是感觉。

- 混合检索排序完善；预注册判据的对比实验报告（沿用生产系统的 pilot 方法论）
- 增量索引 + 崩溃恢复
- 任意 MCP 客户端 3 分钟接入指南

## v0.3+（按面试反馈择机）

- 多 vault 支持 / 权限分层
- 嵌入式主项目的联动叙事：同一套「AI 工作流文档化」方法论在两个仓库复用
