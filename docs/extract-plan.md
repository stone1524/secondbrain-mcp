# 脱敏抽取计划（个人生产系统 → 开源 v0.1）

> 目标：把真实运行的第二大脑网关抽成可发布的开源框架，**一根线都不碰隐私**。
> 原则：先定红线，再动代码；每个模块「抽取或重写」单独决策。

## 红线（任何条目命中即禁止出现在仓库）

1. **个人笔记内容**：正文、标题、frontmatter 里的真实个人数据一律不出库。
2. **95_Private / 人格原始数据**：机制可以描述，内容一个字不出库。
3. **绝对路径**：`E:\Obsidian-AI-Hub\...` 等真实路径不出现；示例一律 `~/SecondBrain` 或 `./demo-vault`。
4. **凭据**：embedding/API key 只从环境变量读取；仓库内只放 `.env.example`（空值 + 变量名）。**任何密钥字面量都不入库。**
5. **审计日志 / 会话记录**：真实运行日志不出库；demo 用合成日志。
6. **人格候选与用户画像数据**：过滤视图的机制开源，数据不出库。

## 模块清单与策略

| 模块 | 来源 | 策略 | 工作量 |
|------|------|------|--------|

| 混合检索（语义+关键词） | 生产网关 | 重写；embedding 走可插拔 provider | 大 |
| 增量索引 | 生产网关 | 重写 + 崩溃恢复测试 | 大 |
